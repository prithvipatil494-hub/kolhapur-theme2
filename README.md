# Kolhapur Theme for Omarchy

A dark, earthy Omarchy theme inspired by Kolhapur — deep maroon from
Kolhapuri chappal leather, warm brass-gold from Mahalaxmi Temple, and
muted stone tones from Panhala fort.

## Palette

| Role            | Color     | Swatch |
|-----------------|-----------|--------|
| Background      | `#1C1210` | ⬛ deep leather-brown |
| Surface         | `#241813` | panel background |
| Maroon (primary)| `#7B2323` | Kolhapuri chappal red |
| Gold (accent)   | `#C98A2C` | temple brass |
| Teal            | `#2F6E5E` | Rankala Lake |
| Stone           | `#8A7863` | Panhala fort |
| Cream (text)    | `#F1E7D0` | warm off-white |

## What's themed

- Hyprland (window borders, gaps, blur)
- Waybar (status bar)
- Alacritty (terminal)
- Mako (notifications)
- btop (system monitor)
- Walker (app launcher)
- SwayOSD (volume/brightness overlay)
- Hyprlock (lock screen)
- Neovim (editor colorscheme)

## Installing

From the Omarchy menu:

```
Install > Style > Theme
```

Then paste this repository's URL, or from the terminal:

```bash
omarchy-theme-install https://github.com/<your-username>/omarchy-kolhapur-theme
```

## Backgrounds

Add your own Kolhapur photos (Panhala fort, Rankala Lake, Mahalaxmi
Temple, etc.) to the `backgrounds/` folder as `.jpg`, `.png`, or `.webp`
files. Use images you have the rights to use.
